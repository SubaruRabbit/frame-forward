# 产品需求文档变更记录

本文件记录产品需求文档的版本变化。日期使用 `YYYY-MM-DD` 格式。

## [v1.0.0-approved] - 2026-08-30

状态：评审通过

### 完善

- 收敛P0机身范围及 Canon 品牌、镜头目录和跨卡口兼容规则。
- 补充注册、密码、会话、改密、注销和无账号恢复能力的产品规则。
- 补充课程预生成、器材事实校验、内容版本和错误反馈规则。
- 补充JPEG校验、EXIF方向、GPS字段清理和无EXIF降级规则。
- 统一AI任务状态、结构化重试、备用模型、任务恢复和评分版本规则。
- 完善App共享层、服务端模块分层及PostgreSQL、Redis职责边界。
- 补充账号凭据、媒体、AI任务、评分记录和课程内容版本数据模型。
- 细化认证、任务查询接口、SSE进度恢复、幂等与错误返回规则。
- 明确作品删除、账号注销和关联派生数据的删除语义。
- 增加10项端到端验收用例和第一版开发完成条件。

### 结论

- 当前需求无阻塞开发的待确认事项，批准为第一版软件开发需求基线。
- 生产部署、账号恢复、公众运营、Canon首批机身适配等事项继续明确延后。

## [v0.3.1-draft] - 2026-08-30

状态：评审中

### 调整

- 明确第一版本的主要客户和验收者是产品负责人本人。
- 第一版本优先完成个人真实可用的摄影闭环，不以规模化运营和增长为目标。
- 核心指标从用户增长指标调整为个人实际使用次数、流程成功率和建议有效性。
- 服务端目标调整为模块化单体本地运行，暂不设计生产部署方案。
- 第一阶段图片使用本地文件存储，仅预留对象存储适配接口。

### 延后

- 生产部署、云资源、域名、CDN、高可用、容灾和多环境方案。
- 找回密码、重置密码、邮箱验证和账号恢复功能。

### 移除

- 从第一阶段项目结构中移除 `deploy/` 目录。
- 从当前阶段验收指标中移除7日留存和30日留存。

## [v0.3.0-draft] - 2026-08-30

状态：评审中

### 新增

- 确定首批镜头品牌为 Sony、Nikon、Canon、Tamron、Sigma 和 Viltrox。
- 确定现场环境分析和照片评分使用 `qwen3.8-max`。
- 确定拍摄方案结构化生成和AI课程生成使用 `qwen3.7-plus`。
- 确定参考图生成与编辑使用 `qwen-image-3.0-pro`。
- 增加Qwen模型路由、配置化升级和上线前评测要求。

### 调整

- 注册方式调整为用户名或邮箱加密码，首期不接入短信验证码。
- 手机号调整为可选用户资料，不作为首期注册验证条件。
- 第一版本不考虑存储成本，不根据存储成本限制图片数量、容量或保存期限。

### 移除

- 从待确认事项中移除首批镜头品牌、Qwen具体模型路由、短信服务和首版存储成本策略。

## [v0.2.0-draft] - 2026-08-30

状态：评审中

### 新增

- 确定首批 Sony 机型：α6700、α7 IV、α7 V、α7C II。
- 确定首批 Nikon 机型：Z5 II、Z6 II、Z7 II、Z8。
- 确定用户必须注册并登录后才能使用AI功能。
- 确定注册用户首期不限制AI产品额度。
- 确定用户图片首期不设置自动保存期限。
- 确定AI模型供应商为阿里，模型使用 Qwen 系列。
- 确定课程首期由AI生成并缓存，不建设课程管理后台。
- 确定首发市场为中国大陆。

### 调整

- 技术项目标识由 `photo-agent` 统一调整为 `frame-forward`。
- 新版本PRD文档编号由 `PA-PRD-001` 调整为 `FF-PRD-001`。
- 相机连接能力首期只保留教程内容，不研究或开发相机直连功能。
- Canon 保留为产品规划品牌，但因未确定首批机型，暂不进入首批可选机型清单。

### 移除

- 从待确认事项中移除注册要求、AI额度、图片期限、模型供应商、课程管理后台、相机直连和首发市场。

## [v0.1.0-draft] - 2026-08-30

状态：评审中

### 新增

- 定义以微单摄影为核心、兼容手机辅助拍摄的产品定位。
- 确定首期支持 Sony、Canon、Nikon 的 APS-C 与全画幅微单。
- 增加相机、镜头、三脚架、闪光灯、ND、CPL、反光板和持续灯管理。
- 增加主力相机设置与基于用户器材的 AI 推荐机制。
- 增加摄影基础、微单操作、品牌型号、连接传输、镜头和附件课程。
- 定义现场分析、拍摄方案、参考图生成、作品评分和重拍对比流程。
- 确定 Android 客户端使用 React Native 与 TypeScript。
- 确定服务端使用 Java 21、Spring Boot 3.5.8 和 Spring AI Alibaba。
- 确定服务端采用模块化单体，AI 采用确定性 Graph/Workflow。
- 定义 App 与服务端的独立项目目录及 OpenAPI 契约边界。

### 待确认

- 产品正式名称及文档负责人。
- 首批具体机身与镜头型号清单。
- AI 模型、图片保存期限、免费额度及课程内容生产方式。
